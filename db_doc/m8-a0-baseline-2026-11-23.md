## 1.2 实际实体与权威写路径

| 对象 | 权威写路径 | 位置 |
|---|---|---|
| 课程路线/发布版 | `LearningRouteRepository.saveLearningRoute`（CAS）/`insertLearningRouteVersion` | `postgres-learning-route-store.ts`，payload JSONB |
| 课次↔正文锚点 | `RouteLessonLink{routeId,number,lessonId,routeVersion,firstContentVersion}`，`insertRouteLessonLink` | 发布时建立，`getRouteLessonLinkByLessonId` 反查 |
| 课次私人事实（学完） | `NativePrivateLearning.privateCommand(action:'complete')`，组件级 revision CAS + `appendLearningHistory` | `native-learning.private.ts`；consent 门控 `privateEnabled` |
| 计划/任务创建 | `ManualPlanningService.confirm`（operation 幂等回执 + `lockPlanningOwner` + 标题/日期去重 + 日容量） | `manual/manual-planning.service.ts` |
| 任务执行命令 | `LightTickTaskService.command`（状态机 + baseVersion CAS + 执行事件） | `lighttick-task.service.ts` |
| Today | `LightTickTodayService.get`：业务日 `businessDateAt(instant, profile.timezone)`，`scheduled_business_date` 列优先 | `lighttick-today.service.ts`；渲染 `taskData`（`lighttick-route-mappers.ts`） |
| 学习→行动对账（B 域） | `completionSink → LearningActionProjection.onLessonCompleted`：内容事件 + 当天 `completion_mode:'content'` 日计划对账 | `learning-action-projection.ts`，runtime `actionsEnabled` 门控 |

**最小关联存储结论（design 决策 1 落地）**：不需要新关联表。`normalized_target={kind:'plan',plan_id:routeId,lesson_no}` 已是行动域唯一关联锚点；把它提升为 `zook_lighttick_tasks.learning_target` JSONB 可空列（迁移 151，教练线段），附固定版本字段 `route_version/lesson_id/content_version` 与 `purpose:'learn'|'review'|'apply'`。目标↔路线关系由 task 的 `goalId + learning_target.plan_id` 承载，确认前只存在于 proposed plan 的 `proposal.draft`，不写执行实体。

**联合完成事务结论**：`LightTickOwnerTransactionGate` 嵌套事务复用同一连接与 owner 锁（`postgres-lighttick-owner-transaction.ts`），task 完成与课次学完可在**单个 PG 事务**内原子提交，无需持久事件收敛。失败恢复沿用两层既有幂等：v1 路由 `idempotent()` 回执 + `learning.command` 私有命令回执。

**S0 5.2 改投影落点**：`onLessonCompleted` 在写 B 域内容事件之外，按 `learning_target` 匹配**当天业务日、purpose='learn'、未终态**的 A 域 task 显式完成（事件 payload 记录 lesson 证据）。review/apply 与非当天任务不动——与 spec「单独学完不自动关闭其他安排」一致：当天 learn 任务的完成标准在排期确认时已被用户显式确认为「学完该课」。B 域对账保留（5.3 停 B 在 A 完全接管后，不在本切片）。

## 1.3 预算、日期/时区、来源版本、旧客户端与生命周期

- **预算**：`validateManualDraft` 草案内日累计 ≤1440；`confirm` 计入既有非 cancelled 任务日占用；`assertDailyCapacity/assertScheduledCapacity` 走 `resolveGoalConditions`（C3 表 B 权威，回退开关默认 false）。周容量由 goal-context 确认条件承载，本切片不改。
- **日期/时区**：任务日期 `scheduled_for` 支持 date-only；`scheduled_business_date` 列由 store 写入；Today 用账户时区业务日，无设备时区换算。改期 `defer` 不复制任务。
- **来源版本**：确认时重验 `route.publishedVersion === learning_target.route_version`、课次存在于该版 document、`RouteLessonLink.lessonId === learning_target.lesson_id`；正文版本以 link 锚点校验。内容升级不撤销历史（link 保留 firstContentVersion）。
- **旧客户端**：全部新增字段为可选（`learning_target`/`learning_completion`），旧客户端忽略即降级为普通任务；写入不丢来源（列持久化，渲染始终带回）。
- **生命周期**：`assertGoalAllowsExecution` 已处理 paused/recovering/completed/archived；暂停阻止新执行；`available()` 阻止暂停目标新排期（resume_goal 显式恢复除外）。删除覆盖：`zook_lighttick_tasks` 已在 `LIGHTTICK_OWNED_TABLES`，新列随表删除，无新表即无新删除路径。
- **单主学习目标门控**：confirm 时若草案含 learning_target 任务，检查其他目标是否已有未终态 learning_target 任务；有则 409 拒绝（AC20 共享预算未验收前不暴露多目标）。历史无 learning_target 行不受影响。
