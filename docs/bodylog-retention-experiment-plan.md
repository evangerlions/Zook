# BodyLog 留存实验预注册与发布门禁

本文件为准备方案，不是实验启用指令。默认保持关闭；管理员报表只读，不能替负责人批准开启。

## 唯一主指标

完成七日计划并实际打开完成页后的D7本地目标行为留存。账号+实验ID稳定分组；同一实验组的完成页暴露固定首个UTC日期；目标日完整结束才进入分母。D1为辅助指标；未成熟/无样本用null，不能显示0%或宣称改善。对照组保留现有续行动提示与入口，实验组只强调已有习惯，不新增打扰提醒。

账号只从明确授权事件可观察；报表必须同时披露授权覆盖与业务邀请账本。不同实验/组别的行为不混算。按固定ID保持实验覆盖整个收集、随访、七日离线迟到窗口；不得中途改ID/分配比例再合并结果。若必须更换设计，暂停新暴露并保留旧队列窗口，建立独立新实验。

## 样本规划

使用两独立比例正态近似：双侧alpha=0.05、功效80%，零假设合并方差、备择非合并方差。参考官方 [statsmodels 样本规划文档](https://www.statsmodels.org/stable/generated/statsmodels.stats.proportion.samplesize_proportions_2indep_onetail.html)。这属于规划近似，忽略远侧尾部；不是效果或精确功效保证。当前实现先按每组相同成熟人数计算下限，实验组比例低于50%时仍要求两组各达到该人数，不能按总人数提前结束。

p0必须来自同定义、已成熟且同授权口径的历史样本；delta是预先确定的最小有业务意义的绝对提升，不能看结果再选择。代码要求声明成熟样本目标不低于规划下限；原始入组量另按历史授权覆盖、暴露率和流失率上调，不能将所有注册量作为有效样本。小样本/极端比例、反复实验或复杂分层需分析负责人另做适当统计复核。

## 观察、停止与回滚

- 至少14日入组，末个暴露账号至少8日随访，再保留7日迟到数据窗口；并满足两组预设成熟人数。日历周期和样本目标两者都满足后才分析主指标。
- 不因中途显著性提前结束，不混入试跑账号，不反复调整差异/窗口。若流量不足，报告不足与事先审阅的延期，不宣称无效或有效。
- 保护本地快速记录、账号失败率、重复远程动作数及本地操作P95；出现隐私泄露、重复发奖/写入或不可恢复账号问题立即停止新实验暴露，保留调查证据。其他阈值按声明的预设护栏人工审核，不把本页字段误当成已经接入全部实时监控。
- 关闭实验配置即不再授权实验强调入口；客户端前台刷新，账号默认未授权或撤回后队列清理，服务端业务开关仍控制写入。本地习惯记录不依赖实验或联网。
- 负责人分别签认发布、数据质量和最终分析；没有成熟样本、置信区间与护栏检查不能给出留存提升结论。
