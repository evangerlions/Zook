# 独立资料库与跨研究引用子任务

属于 U5 专题大项，不改变原 27 项计数。保留现有未提交修改，只用合成账号/本机专库验收；不读取真实历史、不迁移真实数据、不发布。

- [ ] 合同/领域：独立 owner＋资料 ID、不可变版本与摘要、CAS/持久原请求、分页历史和归档恢复；明确时间/来源/反证。
- [ ] 引用：研究固定资料 ID/版本/摘要，跨标的研究复用；改版不替换旧引用，归档阻止新引用，保留旧历史和兼容写入；AI 冻结已选原文，授权导出及共用删除覆盖。
- [ ] React：独立资料编辑与三方冲突核对、历史/归档恢复、研究选择精确版本/移除及回看，原请求与离线草稿保留。
- [ ] 验收：合同/类型/领域/HTTP、真实 PostgreSQL、Chrome 主流程/恢复及旧研究/AI 回归，固定候选和证据后更新。

边界：文本/来源链接不自动抓取，不导入真实文件或私人历史；旧采集/文件解析、全部专题迁移与外部门禁仍待执行。
