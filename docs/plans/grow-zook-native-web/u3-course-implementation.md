# U3 正式路线与 worker 实施切片

沿用候选分支和原任务表，原表两项在联合验收后更新。只用合成账号，不运行旧 Python、不访问真实历史、不发布。

1. 正式路线：新增独立 route/draft/published version、阶段和课次蓝图，周节奏/自由节奏、先修关系、复盘、已发布课次不可改变；正文复用 NativeLearningService 和不可变 publication。迁移、删除与权限覆盖新表。合同 /learning/routes，owner 事务 CAS/原请求回执。验证规则黄金样本、PG 并发/回滚、分页/旧版本/显式完成进度。
2. Worker：复用 LightTick worker/共享队列、平台 LLM/files；任务持久状态、预算预留、租约/fencing、取消、超时、重启扫描。AI 只生成草稿，明确审阅后发布，重复投递不重复发布。资料采集有限来源、授权文件和有界正文，不把私人笔记自动发送模型。验证丢队列/过期租约/取消/跨 owner/撤权/重复发布。
3. 客户端与兼容：React 路线/阶段/进度/任务操作接现有持久编辑器；旧 learning-progress 维持容量和权限；双端保留旧接口并验证新权威进度/学习接续。运行合同 generate/check、专项类型、真实 PG、Chrome、双端适用测试与 U1/U2 回归后记录固定产物及证据。

每个切片标准：合同与实现同轮；正式命令匹配 owner/资源/版本/原请求；原任务表不以构建通过代签。
