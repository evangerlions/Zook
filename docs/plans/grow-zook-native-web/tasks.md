## 每个实现任务的拆分规则

开始每个切片先列合同/状态与可验证标准，再分成独立的资源或交互步骤；每步写明具体文件、依赖与测试命令。上表某项包含多个领域时必须继续拆分，不一次完成整块。新 API 同轮提交 canonical OpenAPI、generate/check 结果、Node 实现、React 接入和文档；运行时不得读取合同源目录。后端请求/用户/stream/job 状态不存单例字段。
