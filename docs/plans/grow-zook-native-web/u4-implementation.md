# U4 知识与回看切片

沿用候选分支，保留用户工作树，只用合成账号，不迁真实数据、不发布。

1. 知识/认知：owner 隔离稳定 ID、CAS、原请求回执、不可变历史、来源 kind/id/version、显式归档/恢复；正文冲突保留三份，来源撤权时停止读取/导出，不以文字相关性伪造关系。
2. 回看：同 owner 事务取得一致记录/课程/私人输入/执行反馈/知识快照；分页绑定筛选与事实摘要，变化显式重建，容量超限拒绝而非静默截断；统计独立口径，不从阅读或数量推断掌握。
3. 客户端/导出：React 搜索/时间线/统计/来源关系及编辑历史；原生可信 Web 接续入口。本人授权数据导出不含工作密钥或原始内部回执。验证 PG 回滚/重连/切号/撤权、Chrome CAS/丢响应及双端适用入口后才更新原任务表。

旧投资研究、认知文章采集发布、全域缓存删除与金融/混合负载门禁不以基础投影替代，留在对应逐行为清单。
