## 实际实现

- Grow根目录新增React/TypeScript/Vite静态前端，源码保留原仓库。真实LightTick账号登录/刷新/退出，HttpOnly刷新Cookie、内存access token；同页刷新单飞、同源Web Locks协调Cookie操作、多标签会话变更通知。
- 记录创建、编辑、搜索/分页、历史、归档/恢复；本机输入与原key/body持久化，409比较两份文本，网络未知结果不自动重放。文档独立草稿槽，重载恢复且不会覆盖另一个标签。
- 手动基础计划草稿、编辑、版本冲突审阅、明确确认；今日任务开始/完成/改期/跳过/取消。直接复用既有LightTick领域API，不创建网页副本或新App。
- Zook既有Web进程增加默认关闭的静态挂载、限定页面fallback、资源404/HEAD/方法/路径/摘要校验、固定产物导入和Docker静态目录；无Grow服务/容器/端口。
- 修复真实浏览器暴露的共享代理POST认证挑战问题：可重放Blob体保持401与二进制字节，不再因字节体detached转换为502。保留红/绿回归。
- 修复sync push原子性：命令、事件/变更和回执在同一owner事务内提交；存储故障回滚，匹配已接受请求并发重试返回duplicate；原冲突/拒绝的重放仍为conflict/rejected，不能误清原生队列。未知存储错误不伪装持久拒绝。
