研究保存只写事实，不更改资产、不创建行动、不执行模型/策略；已有 worker 继续负责行情。本人授权导出增加当前档案、全部版本及每版原 key/body 回执；新增表加入共用产品/平台 owner 删除，并由表清单自动检查保护。500 档案/owner、100 版本/档案（含归档/恢复）、30 资料/行情引用、12000 字符/长字段、200000 字节/写入；导出超过 5000 版本/8 MiB 显式失败，不返回截断结果，完整分块迁移另列待办。

## React 与故障行为

实际字段表单、资料编辑、可选账户和已确认行情来源选择；没有通用 JSON 编辑器替代工作流。保留基线、本机、云端三份内容；冲突后解除被拒绝的原请求，再明确保留本机编辑并采用云端基线，或明确替换为云端副本。保存未知结果不会重建 key/body，刷新后仍可从同 owner/instrument 的草稿恢复原请求。归档不删版本，恢复后再编辑。

列表/历史/来源目录在离线、前台恢复时失效并重新核对授权；本机输入与原请求保留。游标失效重建只读列表。请求序号与卸载标记阻止迟到回调覆盖当前选择；React key 对来源、条目和版本分别命名。

Chrome 过程中修复了长文本/选择框可访问名称不稳定、长行情来源 ID 按钮和长标的账本字段的窄屏溢出。保留真实键盘和宽度断言，没有以关闭检查代替修复。
