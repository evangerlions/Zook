## 功能与明确变化

新增“模型与设置”页面和服务地址→密钥与模型→核对三步引导，选择个人/平台模型、保存配置、测试当前输入（不保存）、测试已保存配置、取消测试、读取云端/清除个人配置和本页密钥输入。编辑、读取、保存、清除本身不调用模型；阅读已有内容无需配置。测试成功仅代表当次修订可返回完整响应，不代表模型质量或后来编辑的输入已验证。

旧版明文密钥放在账号作用域的浏览器 localStorage；本轮改为 **当前 LightTick 账号的服务端加密配置**，页面和确认动作明确保存范围。浏览器只保存非秘密草稿、基线、原 key、加盐请求摘要和测试身份；密钥仅留当前页内存，不回显、不自动读取或迁移旧浏览器配置，不进入普通回执、队列、正文或授权导出。服务端使用独立私有 KV 主密钥和既有 AES-GCM，绝不复用可能下发给客户端的日志上传密钥；并发初始化通过 set-if-absent。密文绑定 owner/修订/配置，临时测试还绑定测试 ID。

正式配置 CAS＋幂等回执原子写入。未知结果可通过原 key 读取接受回执；刷新丢失密钥时可重输原密钥，仅当本机原请求摘要匹配才重试同一 key/body，错误密钥不发送。不会自动重建请求。冲突保留本机地址/模型、保存时基线与当前云端元数据，由用户明确采用新修订或替换本机输入。

连接测试独立持久化，不要求先保存或激活配置。未保存输入加密到测试记录，终态/取消/恢复耗尽即清除临时密文。最多 24 次/owner/UTC 日、同 owner 一个未决测试、64 输出 token、60 秒租约、最多三次崩溃恢复，外部 IO 在 owner 事务外。取消、撤权、配置变化与迟到/fence 失效结果不能发布成功；原请求恢复读取同一测试终态。

课程路线/正文 worker、规划会话与普通 AI runner 在创建时冻结模型选择；旧请求未记录选择时保留平台模式。个人模型失败不切平台或模板，配置修订变化拒绝旧个人任务；课程上的已知个人服务失败不自动重复请求，仅崩溃/租约恢复按原边界处理。课程生成和规划草案通过真实执行器验证，不是仅实现了设置页。

当前适配公网 HTTPS/443 的 OpenAI 兼容非流式 chat completions。URL 不允许账号/查询/片段，DNS 全部地址检查并固定连接地址，拒绝内网/保留地址、跳转与压缩响应；请求 256000 字节、响应 2 MiB、总调用 45 秒，业务场景自身预算/超时仍约束。完整响应必须为 stop、非空文本、无工具调用；截断和服务商错误明确失败，不回传错误原文。**浏览器本地配置不等于本机 Ollama HTTP 服务**：所查旧实现本已要求 HTTPS，本轮未增加本机代理或假设服务器 localhost 是用户电脑。
